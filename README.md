## 🔐 Featured Projects

### 1. Detecting Adversarial Prompts in Healthcare Chatbots
[View Repository](https://github.com/alphin20/-Detecting-Adversarial-Prompts-in-Healthcare-Chatbots)

A research project investigating the detection of malicious prompts targeting healthcare chatbots using a fine-tuned RoBERTa classifier.

**Key features**
- Binary classification of benign and malicious prompts.
- Comparison of centralized training and federated learning.
- FedAvg across three simulated clients.
- Evaluation under IID and Non-IID data distributions.
- Model assessment using accuracy, precision, recall, F1-score, and ROC-AUC.

**Technologies:** Python, PyTorch, Hugging Face Transformers, RoBERTa, scikit-learn, pandas, NumPy.

### 2. HEPID — Healthcare RAG Security
[View Repository](https://github.com/alphin20/HEPID-Healthcare-RAG-Security)

An explainable, multi-layer defense framework designed to detect and mitigate direct and indirect prompt injection attacks in healthcare Retrieval-Augmented Generation (RAG) systems.

**Key features**
- Detection of suspicious user queries and retrieved document content.
- Risk scoring combining machine-learning predictions and threat indicators.
- Explainability using LIME.
- Span-level sanitization and post-cleaning verification.
- Medical document retrieval using embeddings and FAISS.
- Streamlit-based demonstration interface.

**Technologies:** Python, DistilBERT, PyTorch, LIME, Sentence Transformers, FAISS, Streamlit, Gemini API.
